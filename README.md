## 🔀 Versionamento

- Versões marcadas com **tags** no padrão [SemVer](https://semver.org/lang/pt-BR/) (`v1.0.0`, `v1.1.0`...).
- Mensagens de commit no padrão **Conventional Commits** (`feat:`, `fix:`, `docs:`...).
- Histórico completo em [`CHANGELOG.md`](CHANGELOG.md).
- Planejamento e padrões em [`docs/planejamento.md`](docs/planejamento.md).

## 🤝 Como colaborar

1. Faça um **fork** ou crie uma **branch** a partir da `main` (`feat/nome-da-mudanca`).
2. Faça commits pequenos e descritivos.
3. Abra um **Pull Request** explicando a alteração.
4. Após a revisão, o PR é integrado à `main`.
