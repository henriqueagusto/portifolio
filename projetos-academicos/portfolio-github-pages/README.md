# 🌐 Portfólio no GitHub Pages

> Página web estática que apresenta meus projetos, publicada direto deste repositório com o GitHub Pages.

**Tipo:** Acadêmico · **Atividade:** Desafio — Criação de Repositório com Versionamento · **Período:** 2026/2
🔗 **Site:** https://henriqueagusto.github.io/portfolio

---

## 🎯 Objetivo

Criar uma vitrine profissional pública, versionada com Git, que reúna meus projetos e possa ser compartilhada no LinkedIn.

## ✨ Funcionalidades

- Seções **Sobre**, **Projetos** e **Contato**.
- Cards de projeto com links para documentação e código.
- Layout **responsivo** (funciona no celular).
- Sem frameworks: carrega rápido e é fácil de manter.

## 🛠️ Tecnologias

- HTML5 e CSS3
- Git (versionamento) e GitHub Pages (hospedagem)

## ▶️ Como executar localmente

```bash
git clone https://github.com/henriqueagusto/portfolio.git
cd portfolio
# abra o index.html no navegador
```

## 🚀 Como publicar

1. No repositório, abra **Settings → Pages**.
2. Em **Source**, escolha **Deploy from a branch**.
3. Selecione a branch **main** e a pasta **/(root)** e clique em **Save**.
4. Em alguns minutos o site fica disponível em `https://henriqueagusto.github.io/portfolio`.
